# alvarochecca-media

Imágenes públicas de los carruseles de @alvarochecca, para que Metricool pueda
publicarlas. Solo se suben aquí las slides finales que se van a publicar.

`alcheca/alvarochecca-instagram/instagram/carruseles/`.

Enlace público:
`https://raw.githubusercontent.com/alcheca/alvarochecca-media/main/carruseles/<carpeta>/<archivo>.png`
